## 已有人物卡更新补漏（用户截图复现，2026-09-22）

上一轮人物卡 UI 覆盖新增，未覆盖已有 JSON 资料更新，因此此前写入链验收结论存在缺口。原生补丁为文件补末尾 LF，而批准候选只给章节补 LF，导致已有角色卡报 `approved_content_mismatch`。本轮已统一所有资源的候选换行语义，保持实际内容哈希严格校验；加入修复前失败、修复后通过的原生集成测试及人物卡 UI/真实模型更新验证。详见 [用户复现后的补修](../artifacts/chat-chain-audit/report.md#用户复现后的补修已有人物卡更新2026-09-22)。

## 待验证风险（不计为已复现缺陷）

- 任一失败工具当前会导致整轮中断：需区分可恢复查询失败、批准拒绝和真实提交错误，验证恢复体验。
- 字数不阻止提交是当前规则，但 goalVerified 不能被理解为字数、结局与内容质量全部通过。
- 导入、联网补全、LAN 多客户端和反馈重试是否也存在项目/任务/迟到事件错配，需要各自端到端验证，不能由聊天缺陷直接推出。
- 知识库引用之外的旧测试和技能可能仍使用已删除接口/旧语义，运行前检查适用性。

## 不应误判为缺陷的行为

空 allowedWriteResourceRefs 当前表示不施加该额外白名单，不代表免批准或禁止全部写入。取消后保留此前已正式提交的补丁符合逐补丁事务语义。模型文本验证与工具验证分开是合理边界，但 UI 必须表达清楚。
