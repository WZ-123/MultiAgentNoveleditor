# 《雾港回声》文风记忆（style:memory）

## 视角
- 第三人称限知林雾：始终贴住林雾的所见、所闻、所感，只写他知情与感知的范围；不写他不知道的事，不替他者作内心独白。
- 当林雾遗忘时，叙事随之缺省——他记不得的，读者也不得而知。

## 节奏：短中句交替
- 短句为主，中句承接，短中交替；句子长度随情绪收紧或放慢，段落不齐头等长。
- 独句成段的短句只用于关键处，不滥用；避免超长复句与并列堆叠。

## 情绪：动作与物件承载
- 不直写情绪词（悲伤、愤怒、恐惧），让动作与物件替人说话：擦一只杯子、把旧鞋放回门框、翻过缺页的日记。
- 每章至少由一个物证驱动（钟、名单、旧鞋、遗书、原稿），真相由物件逐件揭晓，不靠讲解。

## 对白：潜台词
- 话里有话；回答常偏离问题；沉默、重复、答非所问都是台词。
- 关键信息宁可少说，不可说破；读者从"没说出的那句"里推断。

## 叙事规则（必须保持）
- 视角不越界；情绪不外露；真相交给物件；潜台词留给对白；节奏服从短中交替。
- 收束落在具体动作或物件细节，不拔高、不总结。

## 禁令
- 禁止套话：命运、宿命、救赎之类直陈。
- 禁止"不是……而是……"式转折——它把结论说破，剥夺读者推断。
- 禁止总结式升华：不写"这一刻，他懂了""他明白了一切"式的收束。
- 禁止滥用比喻：比喻须回落到物件与动作本身；潮汐、雾、水位、钟表为喻体，克制使用。
- 避免成语堆砌与形容词过量。
