# 文风记忆（style:memory）

## 视点
- 第三人称限知，全篇以林霁为唯一视角人物，读者与林霁同步获知信息。
- 不切他人内心；他人的情绪只通过动作、物件与对白被林霁观察到。

## 句式与节奏
- 短中句交替；节奏由动作与物件驱动，不为修辞服务。
- 段落以具体动作或物件收束，不甩形容词。

## 情绪承载
- 情绪用动作和物件承载：潮声、盐雾、油毡布、旧信封、气送管、气压图、指节敲桌、拆信刀。
- 不直接抒情，不写“她感到……”，改写“她把信翻过来，纸角卷着”。

## 对白
- 有潜台词；角色说话绕、克制、具体。
- 用短句与具体名词；留白让读者补足情绪。

## 禁令（禁用清单）
- 禁止滥用比喻；比喻必须有具体功能，且低频。
- 禁止“不是……而是……”句式。
- 禁止“仿佛”“好像”堆叠。
- 禁止“难以言喻”“无法形容”类逃避式表达。
- 禁止总结式升华（句尾喊口号、提炼中心思想）。
- 禁止机械排比与套话。

## 基调
- 现实质感的沿海奇幻悬疑。
- 克制、具体；奇幻只呈现法则的“表现”，不解释法则本源。
